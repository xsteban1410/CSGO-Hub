# Zombies

Each wave is a round. Zombie bots (T) only carry knives and respawn endlessly; you (CT) have infinite money and ammo.
Survive the wave time to move on; lose and the wave repeats. Normal, runner (fast, weak) and tank (big, slow, triple
health) zombies; bullets push them back and fire burns them; killed players come back as zombies; fog.

Settings (`--set` or your own mode): `modo_z_oleadas` (5), `modo_z_base`/`modo_z_incremento` (6/2),
`modo_z_vida`/`modo_z_vida_oleada` (250/75), `modo_z_velocidad` (1.2), `modo_z_retroceso` (1.0), `modo_z_infeccion` (1),
`modo_z_niebla` (1), `mp_roundtime` (1.5). `zombies_estado` in the server console shows the wave.
